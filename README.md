## Usage

This package contains best practices and skills for AI-assisted development.

## Skill structure checks

- `npm run skill:lint` — validates the SKILL.md index contract, link targets, and tile registration
- `npm run skill:budget` — reports the context cost of every skill by tier (`--rules`, `--json`, `--check`)
